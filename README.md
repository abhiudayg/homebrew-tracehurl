# homebrew-tracehurl

Official Homebrew tap for [TraceHurl](https://github.com/abhiudayg/trace-hurl) — Evidence-First Verification Report CLI for Hurl Test Suites.

## Installation

```bash
brew tap abhiudayg/tracehurl
brew install tracehurl
```

## Update

```bash
brew update
brew upgrade tracehurl
```

## Verify

```bash
tracehurl --help
```
